# DSH Claude 翻译插件

**中文与 DSH 对话，实际用英文调用本机 Claude Code，回复保留英文原文并提供中文对照。**

不需要每次复制文本到翻译软件，也不用为 Claude 重新申请一套 API Key。
本机已登录的 Claude Code 仍负责真正的任务执行。

## 安装条件

- 已安装并运行 DSH Web。
- 本机已安装 Claude Code，并完成有效登录。
- 已启用 [dsh-codex-claude-cli](https://github.com/ChangfengHU/dsh-codex-claude-cli)
  适配插件，把本机 Claude 注册成 DSH 可选模型。
- 翻译来源任选一种：
  - 本机已安装、已登录且已接入 DSH 的 Codex，不需要额外翻译 Key。
  - 配置一个千问 Qwen API Key。
  - 配置一个 DeepSeek API Key。
  - 使用 DSH 已配置好的其他非 Claude 模型通道。

仅仅存在一个 CLI 可执行文件，不表示它已经登录或已经接入 DSH。
插件不复制登录凭据，不绕过 Claude/Codex 认证。

## 一次配置，正常聊天

1. 在 DSH 插件管理里安装 CLI 适配插件与本翻译插件，启用 Host/Web 两端。
2. 在 Host 没有任务执行时重启，刷新页面。
3. 打开会话的 **Translation → 翻译设置**。
4. 选择已有 Codex/模型通道，或设置千问/DeepSeek Key。保存并测试。
5. 在原生模型选择器中选 Claude Code，开启“本会话启用”。
6. 继续在原来的输入框聊天，无需另开输入框。

默认不擅自更换主模型、不自动全局开启翻译。
已有英文输入可以直接使用，纯英文自然语言会跳过输入翻译。

## 看得到真实调用

时间线按每次调用展示：

- 原始中文输入与实际转发英文。
- Claude 原始英文回复与中文显示译文。
- 输入翻译、Claude 执行、回复翻译三个阶段的耗时和状态。
- 出错或取消时的具体状态。
- 按需加载完整请求，下载完整调用记录。

“实际转发”指 DSH 交给 Claude 适配插件的请求，不是抓取 Claude 私有 HTTP 协议。
原生 CLI 内部指令、CLAUDE.md、内部工具循环、隐藏推理不在捕获范围。

## 速度和保留策略

翻译模型可配置。本机 Codex 适合复用登录，但不必然最快。
短文本可测试 Flash 级模型；型号、地域权限和翻译完整性都必须实际验证。
插件使用文本块及句子缓存，避免反复翻译相同历史与静态上下文。

引用的中文标题、按钮文案、文件名作为原始数据保留；未加引号的路径和 URL
遇到中文标点会正确结束，后半句仍需正常翻译。纯代码回复不再付费生成显示译文。
真实验收使用普通业务需求，不在消息里提及插件、不指定英文答案。

整个插件 profile **最多保留最近100条翻译调用**，超出自动清理旧记录和无引用共享文件。
不删除 DSH 原始聊天。页面每页20条，只有展开的调用加载详情。
64 MiB 总大小和默认7天保留期仍生效，超过这些上限时也会清理更旧记录。
正在执行的记录不会被清理，因此执行期间可能暂时超过100条。

支持千条记录的分页/重启/去重专项测试，数据只在临时测试目录里构造，
不会调用大模型或混入真实会话。测试容量不是同时执行1000个模型请求的承诺。

## 安全边界

代码、路径、URL、图片、结构化 JSON 和工具实参/结果是原始数据，不应随意翻译。
因此要求是“交流用英文”，不是把所有中文字符从代码和数据中删除。

输入翻译格式不完整、漏句或破坏受保护字面量时，阻止调用 Claude。
回复译文失败则保留原始英文回复，不会把已完成任务伪装成执行失败。
这些检查不能数学证明任意内容的语义等价，高风险操作仍应查看双语对照。

Key 由 DSH 凭据服务保存，不进入仓库、浏览器本地存储或普通配置。
插件不是登录系统，公网 DSH 必须由部署者做好认证与授权。
